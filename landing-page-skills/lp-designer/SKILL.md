# Landing page design

1. Read the brief, actual copy, brand system, assets, and delivery format. Use approved brand tokens. Anchor the page in a recognisable part of the offer when it helps the visitor decide.
2. Wireframe mobile first with real copy. Set the reading order, hierarchy, spacing, proof placement, and primary CTA. For a new or redesigned hero, specify the focal element, what it communicates, and how the composition adapts to desktop. Use visuals that explain the offer, demonstrate the result, or establish proof with usage permission.
3. Specify layout, type scale, spacing, components, breakpoints, and assets. Use shared defaults with documented page overrides. Cover accessible labels, keyboard focus, touch, contrast, reduced motion, and loading, error, empty, success, and retry states as relevant.
4. Render the new or redesigned hero early and inspect both widths. Revise it if the offer, focal element, and CTA compete, or the layout could fit an unrelated offer without changes. Then walk through the full journey on narrow and wide viewports. When a representative buyer is available, observe them find the offer and terms and attempt the action unaided. Otherwise record the walkthrough or independent review and mark buyer observation pending.
5. Deliver the design or build-ready spec with responsive behavior, action states, and unresolved items.

If the UI/UX Pro Max search is available, use design-system search for a new visual direction, domain search for a specific UX problem, or stack guidance for the implementation. Check each result against the brand and actual content.
