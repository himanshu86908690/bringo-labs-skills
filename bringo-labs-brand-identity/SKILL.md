# Apply the Bringo Labs identity

Use the approved identity below as the source for positioning, voice, and visual rules. Resolve prices, scope, case-study figures, and permissions from the latest approved offer materials. Treat examples as applications of the identity.

## Workflow

1. Identify the audience, medium, and next decision from the brief or existing asset. Use the parent brand for company-level materials and Enrollment Engine positioning for live-cohort service materials.
2. Draft around one main message per section or slide. Place relevant proof beside the claim. Give the reader one primary next action. Preserve the client's approved copy and functioning shared components when the task is a visual revision.
3. Apply the palette, typography, and spacing rules below. Use the spacing numbers as starting points and adjust for the content and viewport. Use approved logos, imagery, and font files when available. In drafts, use a plain-text wordmark or a suitable font fallback and identify substitutions that affect fidelity.
4. Review clarity, hierarchy, and accuracy before delivering. For web work, check mobile reading order, visible focus, keyboard operation, and reduced-motion behavior where applicable. Check real form behavior before claiming a submission or booking works.
5. When asked to audit an asset, list the most consequential departures first and give a concrete fix for each. When asked to create or revise, apply the fixes in the deliverable.

## Approved identity reference

## Brand foundation

**Purpose**  
Help businesses grow through clarity, connected systems, and sustainable momentum.

**Core belief**  
Growth is engineered, not improvised.

**The problem we solve**  
Fragmentation. When acquisition, conversion, follow-up, and reporting operate separately, businesses struggle to see what produces revenue and where potential customers drop off.

**Brand promise**  
Bringo Labs connects the parts of growth so businesses can see what works, find where customers drop off, and decide what to improve next.

**What the name means**  
**Bringo** is about bringing businesses closer to sustainable growth. **Go** signals momentum. **Labs** reflects how we work through testing, measurement, and refinement.

## Positioning and messaging

**Parent brand**  
Bringo Labs builds connected growth systems. Lead with the business problem and show how the pieces work together. Make the method visible through clear explanations, documented work, and honest reporting.

**Current flagship offer**  
**Bringo Enrollment Engine** helps India-based, founder-led training businesses running recurring live cohorts attract suitable applicants and see which enquiries become paid enrollments. It connects Google Search ads, a dedicated course page, enquiry qualification, admissions follow-up, and paid-enrollment tracking.

| Service headline | Google Ads for your next live cohort. |
| Supporting message | Reach people searching for the skills you teach. Give suitable applicants a clear path to apply and see which enquiries become paid enrollments. |

Use the cohort positioning on Enrollment Engine materials. Keep the parent brand broad enough to represent future offers. Pull pricing, scope, and case-study figures from the latest approved offer materials.

## Voice and tone

Bringo Labs speaks like a calm, direct strategic advisor. The voice is **clear, confident, curious, practical, and evidence-led**.

- **Diagnose before prescribing.** Explain where the process breaks down before recommending a fix.
- **Simplify before optimizing.** Use the fewest words needed to make the point clearly.
- **Teach before selling.** Show the reader how to think about the decision.
- **Challenge with evidence.** Question the assumption or practice and explain the reasoning.
- **Name the outcome.** Use concrete terms like *paid enrollments*, *cost per admission*, and *available seats*. Avoid generic phrases like *10X growth*, *growth hacks*, and *results-driven solutions*.
- **Put the limits beside the proof.** State what a result measures. If a case study reports leads and ROAS, describe those outcomes directly.

> “Before increasing the ad budget, check which enquiries became paid enrollments and where suitable applicants stopped moving forward.”

## Visual identity

### Colour

| Colour | Hex | Default role |
| --- | --- | --- |
| Charcoal | `#161616` | Primary text, dark backgrounds, and text on lime |
| Grey | `#595959` | Secondary copy and supporting labels on light backgrounds |
| Off-white | `#F0F0F0` | Main light background and text on charcoal |
| Light grey | `#E2E2E3` | Secondary surfaces, dividers, and subtle grouping |
| Lime | `#AACF34` | The single accent for primary actions and selected emphasis |

Build the layout with neutrals. Use lime where it directs attention to an action or a meaningful detail. Pair lime buttons with charcoal text.

### Typography

| Role | Typeface | Application |
| --- | --- | --- |
| Headings | **Neue Montreal** | Headlines, section titles, and prominent figures |
| Body | **Inter** | Paragraphs, lists, buttons, forms, and supporting copy |
| Metadata | **JetBrains Mono** | Eyebrows, step numbers, dates, and short data labels |

Use size, weight, and spacing to make the reading order clear. Keep metadata brief and body copy comfortably readable. On the web, start with 16 px body text, 1.6–1.75 line height, and 12–14 px for short metadata.

### Layout and spacing

**Every word, visual, and space should help the intended reader understand, trust, or act.**

- Give each section or slide one primary job and one obvious focal point.
- Order information around the audience’s next question. For a cohort founder, make the offer clear first, explain how it works, place evidence beside the claim, then show the next step.
- Keep related items close. Use larger gaps to separate topics and give key claims and actions room to stand out.
- Align content to a consistent grid. Keep paragraphs short and line lengths comfortable.
- Remove repeated claims, decorative labels, and graphics that compete with the main message. Keep the specifics and qualifications a reader needs to decide.
- Check the reading order on mobile. When columns stack, each claim should still appear beside or immediately before its supporting proof.

| Web layout element | Starting point |
| --- | --- |
| Maximum content width | 1,280 px for brand pages and 1,240 px for service pages |
| Outer gutters | About 56–60 px on wide screens and 20–24 px on phones |
| Major section padding | About 96–112 px on desktop and 60–64 px on phones |
| Panel padding | 24–32 px |
| Desktop intro width | About 500–570 px |

### Logo and imagery

Use approved logo files and graphic assets when available. Use **Bringo Labs** as a plain-text wordmark in drafts where the logo file is unavailable. Verify exact logo clear space, image treatment, and graphic rules against the Figma reference before formalizing those specifications.

Use captioned screenshots, relevant client marks, founder photography, and simple process diagrams when they help the reader understand the work. Keep third-party marks together in a proof area.

### Website components and behaviour

- Use the shared header and footer. Keep the original wordmark proportions and preserve the mobile navigation drawer, including keyboard focus and Escape dismissal.
- Give each section one primary action. Use a lime button with charcoal text and an 8 px radius as the website default. Use an underlined text link for secondary actions.
- Use fine dividers for service rows and FAQs. Keep form panels quiet, labels visible, and input targets at least 44 px high where practical. Show sending, error, and success states.
- Use the charcoal footer for navigation, contact, and legal details. Stack these groups on mobile.
- Use motion to explain progress, and preserve a readable end state when reduced motion is enabled.

## Final review

1. **Clarity.** Can the intended audience quickly tell what this is, who it’s for, and why it matters?
2. **Hierarchy.** Does the layout make the main message, supporting evidence, and next action easy to find?
3. **Accuracy.** Are the palette, typography, offer details, and claims consistent with the approved sources?
